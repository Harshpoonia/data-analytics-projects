# Student Performance Analysis

## Project Overview

This project analyzes student academic performance data to identify the factors that influence student outcomes.

## Objective

- Understand the dataset
- Perform data cleaning
- Conduct exploratory data analysis (EDA)
- Create visualizations
- Generate actionable insights

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
